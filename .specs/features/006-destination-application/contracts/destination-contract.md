# Destination Local Contract — v1

Inspect [the plan](../plan.md) and [the spec](../spec.md) for behavior and ownership. This artifact defines local Rust/Tauri DTO boundaries, not HTTP endpoints.

| Boundary | Input | Output / invariant |
|---|---|---|
| destination snapshot | active session ID | session ID, cancel generation, version, phase, capability, selection, badge metadata; no text |
| destination menu | current session/version | opaque entry tokens, foreground-first non-Handy entry, deduplicated windowed apps, FrontmostAtEnd; no window titles |
| choose destination | session ID, expected version, opaque token or FrontmostAtEnd | updated snapshot/version before Inserting; stale/closed/frozen request refuses unchanged |
| remove destination cross | exact session ID/version, phase before insertion | same FrontmostAtEnd mutation as menu; one click, ≤200 ms badge update, localized Remove destination label; no menu open, keyboard focus or persistent setting change; late/frozen click refused |
| activation | frozen application identity, cancel generation, monotonic deadline | app_closed, activation_failed or dispatch permission; never launch/retry/fallback |
| pre-dispatch guard | frozen resolved identity and generation | check immediately after configured delay, before first key/text/script; fail means zero new dispatch |
| settings get | output key return_to_dictation_app | same 008 success envelope/revision, value and capability availability/reason |
| settings set | bool, expected revision when supplied | 008 shared commit; unsupported→unavailable/5, invalid→validation_failed/2, stale→revision_conflict/3 |
| recovery access | outcome/session opaque transcript_ref | retained final text for trusted native consumer while current; expired reference explicitly unavailable |

`InsertionOutcome` fields: session_id, cancel_generation, outcome_id (dedup key), target optional stable identity, destination_source, status, method_outcome optional, reason optional, history_status, history_entry_id optional, transcript_ref optional, completed_at. Status: insertion_attempted/failed/clipboard_handed_over/skipped/cancelled. Reason: app_closed/activation_failed/insertion_failed. History: saved/not_saved/failed from actual WAV/save result. No verified field flag and no public plaintext event.

007 produces the smart-paste method result after destination activation. `method_outcome` preserves read observed (007's "insertion attempted, read observed"), not read, permission missing, typed, clipboard handed over, insertion failed, inserted, verified, or uncertain. Inserted, verified/read observed/typed map to insertion_attempted while preserving exact method evidence; 006 claims no field verification of its own. Not read/permission missing/uncertain/insertion failed map to failed with insertion_failed reason and preserved method detail; clipboard handed over maps to clipboard_handed_over and displays the remote-screen clipboard information, without Enter or failure recovery from that result alone. If no method ran or a legacy method has no detailed result, method_outcome is absent. Await 007's direct read-back/clipboard decision outcome off the main thread; enqueue success is not that terminal result.

Producer: terminal destination orchestration in actions.rs; consumers: 009 Enter policy, 010 reason/recovery bubble. For smart paste, only inserted, verified/read observed/typed permit 009 Enter; 010 receives not read/permission missing/uncertain/insertion failed and destination failures with the retained reference. 007 owns pasteboard snapshot/publication/read timing/restoration; 010 Copy changes pasteboard changeCount so 007 abandons pending restoration, with no recovery-window API in 006. Registration is optional; missing feature never prevents terminal outcome. Native registry stores transcript separately from UI event DTO. Session/version/cancel generation reject late/duplicate delivery. Reason presenter capability and acknowledgement transfer display ownership to 010; preserve minimum ≥4 s visibility and visible-overlay fallback if no ack. Style-none before 010 has no bubble; no certified reason presentation claimed then.

007 adds paste_method=smart_paste to the same 008 output-domain descriptor and transaction service, refused outside macOS with validation_failed/2; 006 only adds return_to_dictation_app. Windows reliable paste remains unchanged. No clipboard recovery duration setting is introduced.

Configuration envelope is exactly `{ok:true,revision:N,data:{...}}` or `{ok:false,error:{code,message,details:{...}}}`, newline once on stdout under --json, diagnostics on stderr. Existing 008 exit mapping remains 0 success, 1 persistence/internal, 2 usage/validation/conflict/limit, 3 revision conflict, 4 not found, 5 unavailable. No alternative lock, writer or transport. Pure reads/no-op preserve revision; failed validation/capability/CAS leaves disk unchanged.

007 alone owns the AX-first chain: exact expected selected-range replacement gives inserted, verified; unchanged field allows clipboard fallback; unexpected change gives uncertain without fallback. Clipboard restoration requires a post-Cmd+V read, 300 ms quiet after the last read and an 8 s cap after the first read; no read within 800 ms gives not read with no restoration and transcript left on clipboard. Jump Desktop retains 1.5 s quiet / 3 s no-read exceptions. No 006 timer, restoration or duplicate insertion; newer changeCount, including 010 Copy, abandons restoration. Consumer guards in 009 still apply to every eligible result.
