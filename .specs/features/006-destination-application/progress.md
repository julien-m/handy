## Step 4 — notes

- **Flow delivered:** `actions.rs` reads the destination right after the settings, before any overlay is shown, and commits it only when `try_start_recording` succeeds (a failed start discards it); `stop` takes the dictation ticket and marks the session processing; the final text goes through `destination::delivery::insert_final_text`, which runs `insertion::Orchestrator::deliver` on a blocking worker: freeze (menu closed, later choices refused) → paste method `none` skips activation (`skipped`) → resolve the instance by identity (captured PID first, one restarted instance, ambiguous or closed fail closed) → one activation request unless already in front → foreground sampling every 20 ms on the worker until in front or 1 s elapsed (999/1000 ms accepted, 1001 ms refused, injected clock) → the existing `clipboard::paste` runs on the main thread as before with a `DispatchGuard` that it calls after `paste_delay_ms` and before the first key/text/script/reliable paste: cancellation, same PID and identity in front (else `activation_failed`, no retry, no reactivation), `DestinationContext`, the 010 verdict (`NoRecoveryConsumer` today), then disposition `Insert`.
