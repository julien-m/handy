# Implementation — Multiple Dictation Shortcuts

This run follows [the approved scope](spec.md) and [the technical plan](plan.md), integrated with feature 008 on 2026-10-14: shortcut writes go through the 008 settings service and the settings CLI has a `shortcuts` domain. Inspect [progress](progress.md) for steps, decisions to confirm, native evidence and the exact pending checks; no AC is certified.

## Files Created/Modified

- Read [settings](../../../src-tauri/src/settings.rs) for the additive `additional_bindings` field (empty by default, omitted when empty, optional in TypeScript).
- Read [identity](../../../src-tauri/src/shortcut/identity.rs) for `ShortcutRegistration`: action, stored shortcut and backend accelerator; Carbon shadows keep the original shortcut.
- Read [conflicts](../../../src-tauri/src/shortcut/conflicts.rs) for normalization with the active backend parser, the inventory of every action and the stored-conflict report.
- Read [list edits](../../../src-tauri/src/shortcut/action_shortcuts.rs) for add/remove/replace/reset planning, the four-shortcut limit, typed refusals and the keyboard-switch repair.
- Read [edits](../../../src-tauri/src/shortcut/edits.rs) for the `edit_binding_shortcuts` and `get_shortcut_conflicts` commands, the choice between the registration delta and the probe (disabled post-processing, cancel outside recording) and the post-processing toggle (`toggle_post_process`: always saved; activation registers each shortcut on its own and returns the ones the OS refuses; deactivation hands a shared slot over).
- Read [registration delta](../../../src-tauri/src/shortcut/registration_delta.rs) for the pure delta (release, add, hand a shared Tauri slot over to the surviving inherited conflict), the activation and deactivation plans of the post-processing action, its rollback and the probe, behind a registration port tested with a fake backend.
- Read [switch repair](../../../src-tauri/src/shortcut/implementation_switch.rs) for the keyboard-switch repair by destination parser and the conflicts a switch introduces (`ImplementationChangeResult.conflicts`).
- Read [live changes](../../../src-tauri/src/shortcut/live_change.rs) for the prepared native changes of `bindings`, `post_process_enabled` and `keyboard_implementation` (quiescence lease, registration before the commit, compensation, Secure Input reconciliation), shared by the settings window and CLI writes routed to the instance through [native changes](../../../src-tauri/src/settings_service/native_changes.rs); [bindings change](../../../src-tauri/src/shortcut/bindings_change.rs) for the per-action preparation and its undo; [keyboard switch](../../../src-tauri/src/shortcut/keyboard_switch.rs) for the lists repaired for the destination (committed in the same revision) and the move of every registration.
- Read [the quiescence lease](../../../src-tauri/src/transcription_coordinator/quiescence.rs) for the lease answered by the coordinator thread and the input gate.
- Read [the CLI domain](../../../src-tauri/src/settings_service/domains/shortcuts.rs) for `handy settings shortcuts` and the mapping of edit refusals to the 008 envelope (allowlisted details in [errors](../../../src-tauri/src/settings_service/errors.rs)); the framework's live-only change is in [domains](../../../src-tauri/src/settings_service/domains/mod.rs), the ordered prepared edits in [the write sequence](../../../src-tauri/src/settings_service/sequence.rs).
- Read [Carbon shadow plan](../../../src-tauri/src/secure_input_shadow.rs) for the macOS Secure Input shadow decisions, extracted from Secure Input with their tests.
- Inspect [shortcut module](../../../src-tauri/src/shortcut/mod.rs), [Tauri backend](../../../src-tauri/src/shortcut/tauri_impl.rs), [HandyKeys backend](../../../src-tauri/src/shortcut/handy_keys.rs), [handler](../../../src-tauri/src/shortcut/handler.rs) and [Secure Input](../../../src-tauri/src/secure_input.rs) for per-shortcut registration and event identity; `change_binding` now replaces the first shortcut through the shared checker and `reset_binding` restores the single default.
- Inspect [the coordinator](../../../src-tauri/src/transcription_coordinator.rs) for owner identity; `on_input` was split into steps without changing single-shortcut transitions.
- Inspect [the native entry point](../../../src-tauri/src/lib.rs) for the two registered commands and [generated bindings](../../../src/bindings.ts), exported by the app's own Specta builder.
- Read [the shortcut list](../../../src/components/settings/shortcut-list.tsx), [its model](../../../src/components/settings/shortcut-list-model.ts) and [the key chip](../../../src/components/settings/shortcut-chip.tsx); the existing recorders gain a capture mode; [general](../../../src/components/settings/general/GeneralSettings.tsx) and [post-processing](../../../src/components/settings/post-processing/PostProcessingSettings.tsx) settings show the lists; [store](../../../src/stores/settingsStore.ts) and [hook](../../../src/hooks/useSettings.ts) expose `editBindingShortcuts`; every locale gains `settings.general.shortcut.list`. The legacy `updateBinding`/`resetBinding` throw [typed refusals](../../../src/lib/shortcut-edit-failure.ts), which [the recorders](../../../src/hooks/useShortcutFailureText.ts) translate. [The post-processing toggle](../../../src/components/settings/PostProcessingToggle.tsx) always turns on and shows a translated toast (`settings.debug.postProcessingToggle.shortcutRefused`) for each shortcut the OS refused; the store keeps those refusals and the list flags their rows, which stay editable.
