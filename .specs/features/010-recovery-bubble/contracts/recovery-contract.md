# Recovery Bubble Local Contract

Inspect [the technical plan](../plan.md) for decision, reason, threading, testing and dependency context. Local Tauri/native commands and a settings descriptor only; no HTTP endpoint/OpenAPI.

| Boundary | Contract |
|---|---|
| Rollout gate | Behind 006's `destination-return` Cargo feature (`destination::rollout`). Closed (default build): no session, `dev`'s `paste-error` on failure (Linux and 007's sessionless path included), no bubble, `RecoveryPort`, classification or setting (`not_found`/4, checked schema unchanged). Open: this contract |
| 006 input | `InsertionOutcome` as fixed by the 006 plan: `dictation_id`, `destination_generation`, `outcome_id`, `target`, `destination_source`, `status`, `method_outcome`, `transaction_id`, `reason`, `history_status`, `history_entry_id`, `transcript_ref`, `completed_at`; opaque `transcript_ref` resolved by the trusted native manager; dedupe by `outcome_id`, stale identity discarded |
| Recovery instance | Native immutable full text, unique bubble_id plus dictation_id/destination_generation/transaction_id (006's decimal `String`), phase, `BubbleReason` (`AppClosed`, `PinnedAppNotRunning`, `ActivationFailed`, `InsertionFailed`, `NoTextField`; distinct from 006's `context::RecoveryReason`), target name (session snapshot, then `WorkspacePort::instances`, then the localized noun), target name, history_status and late-read flag; no public verified flag |
| Surface snapshot | Targeted preview/reason/history metadata, current bubble identity, actions/capabilities; no full text app-wide broadcast |
| Action | Copy/Close/explanation/drag request with exact current bubble identity; stale closed instance rejected, never affects successor |
| 007 method outcome | No separate adapter: `InsertionOutcome.method_outcome` carries 007's `PasteOutcome.kind` wire value (`inserted_verified`, `read_observed`, `not_read`, `permission_missing`, `uncertain`, `typed`, `clipboard_handed_over`, `insertion_failed`); only `inserted_verified` is field-verified; 006 waits for the terminal read/no-read result before producing the outcome |
| 007 late read | `PasteDiagnostic { dictation_id, transaction_id, late_read_observed }` after `not_read`, received through a native sink added to `smart_paste::app::EventDiagnostics` and matched with `transaction_id.0.to_string()`, updates the matching current bubble in place (none in copy-to-clipboard mode, 007 limitation) ("may have been pasted after all"); no second bubble, no outcome, disposition or Enter change; stale, closed or repeated diagnostics ignored |
| 007 AX chain | 007 tries AXSelectedText and compares reread with expected replacement before clipboard (outside special-app strategies); unchanged permits fallback, unexpected change → uncertain with no fallback; 010 never retries insertion; current 007 direct AX budget ≤250 ms including ≤150 ms readback, separate from 010 classification; 007 owns destination-PID guard and clipboard handling |
| 007 restoration | macOS smart paste owns read-confirmed restore: 300 ms quiet after LAST post-Cmd+V read (Jump 1.5 s), capped 8 s after FIRST read; no read under 800 ms (Jump 3 s) → not read, NEVER restore for this dictation including late read/quit/new output; on the existing executor check publication changeCount and write without interleaving deliberate Copy; changed count abandons restoration, no window cancellation API |
| Deliberate Copy | Existing clipboard executor writes full plain text; success changes changeCount even for identical text and closes matching instance, so pending smart paste restore abandons; failure/partial write retains text/surface and reports error, original restore guard remains authoritative; existing Windows/Linux Copy paths kept |
| Drag | macOS native plain-text full payload plus preview, only copy; hidden during session; operation none restores only current instance, accepted closes/logs drop accepted without field verification or text |
| Enter veto (shared with 009) | Single contract: 006's `RecoveryDisposition { Pending, Insert, Recover, Cancelled }` changed only by `DestinationManager::set_disposition`; 010 implements `RecoveryPort::before_insertion(&DestinationContext) -> PreInsertionVerdict { Insert, Recover(RecoveryReason) }`, called synchronously by 006 in the first accepted `DispatchGuard::check()` after `paste_delay_ms` (main thread for main-thread methods), with an AX budget of about 50 ms and `Insert` on doubt or timeout; a `Recover(NoTextField)` verdict is recorded under `(dictation_id, destination_generation)` and matched to the resulting `insertion_failed` outcome without `method_outcome`; 010 publishes no other veto; 006 sets `Recover` for that verdict, destination failures and `not_read`/`permission_missing`/`uncertain`/`insertion_failed`; 009 consumes its token only on `Insert` under its atomic claim; only `inserted_verified`/`read_observed`/`typed` allow 009 policy, `clipboard_handed_over` allows neither recovery nor Enter; Copy/drag never auto-submit |
| History | saved/not_saved/failed carried from 006, from the actual save_entry result only, never the WAV (a WAV failure saves a text-only row: saved); kept-in-history explanation only saved, no deletion or new durable guarantee |
| 006 reason presenter | Synchronous `OutcomeConsumer::consume`: copy the transcript through `transcript_ref`, admit and schedule presentation, return `ConsumerAck::ReasonPresented`; `delivery::publish` then skips `paste-error`; if the surface is not visible within 300 ms, 010 emits `paste-error` itself and keeps the text; suppress duplicate indicator only on ack; passive ≥4 s and indefinite bubble, explicit 010 closure events immediate |
| Platforms | Gate open: macOS full bubble; Windows unavailable/activation/method failure without drag; Linux (session with the `FrontmostAtEnd` route) only method failure without drag; unsupported capture uses old method path. Gate closed: `paste-error` everywhere. Native proof: macOS required; Windows/Linux pending release evidence (constitution) |
| Settings | show_recovery_bubble_without_text_field boolean, default true, open build only, no platform capability and no platform note (saved everywhere, acts on macOS only): `descriptor_data.rs` row, `OUTPUT_KEYS` of the 008 output domain, UI write through `tauri_adapter::write`; frozen at dictation start, no current-bubble dismiss on mutation |
| Method configuration | 007 adds paste_method=smart_paste to the 008 output descriptor and domain, refused outside macOS with `validation_failed` and `details.reason = "unsupported_platform"` (D4); macOS reliable paste migration owned by 007, Windows reliable paste and Linux methods kept; no clipboard_recovery_* key |
| Settings commands | handy settings output get KEY / output set KEY true\|false --json and generic get/set; same validation/service/revision renderer as 008 |
| JSON/exits | Exactly {ok:true,revision:N,data:{...}} or {ok:false,error:{code,message,details:{...}}}; 0 success, 1 persistence/internal, 2 usage/validation, 3 revision conflict, 4 not found, 5 unavailable; no transcript output |

All UI/native command inputs are typed and identity-validated. Exported preview never becomes drag or Copy source. Recovery state is volatile; crash/restart survival relies solely on successful existing history save. This is a planned contract, not observed runtime proof.
